# Virtual Tutor — фабрика уроков на Remotion

Отдельный Remotion-проект, который из **текста урока** и **реалистичного
AI-видео ведущего** собирает готовые видеоуроки: интро → говорящий ведущий
с озвучкой и синхронными субтитрами → b-roll с ключевой мыслью → аутро.

## Как это работает

- Реалистичный человек (ведущий) — это AI-сгенерированный клип в `public/`.
  Его нельзя «нарисовать кодом», поэтому он приходит из AI-видеосервиса.
- **Remotion** собирает урок и обеспечивает повторяемость: новый урок = новая
  запись в каталоге + (опционально) новый клип, а структура и брендинг общие.
- **Озвучка генерируется из текста** офлайн-движком `espeak-ng`, а субтитры
  автоматически синхронизируются с полученным аудио.

```
src/lessons.json        ← КАТАЛОГ уроков (единственное, что правите)
src/lessons.ts          ← типы + загрузка каталога и озвучек
src/theme.ts            ← цвета/шрифты/название курса (ребрендинг)
src/Lesson.tsx          ← таймлайн одного урока
src/Root.tsx            ← по одной композиции на каждый урок из каталога
src/components/         ← сцены и оверлеи
scripts/generate-voiceover.mjs ← TTS-из-текста + синхронные субтитры
public/presenter.mp4    ← реалистичный AI-клип ведущего
public/voiceover/<id>.mp3       ← сгенерированная озвучка (на урок)
src/generated/voiceovers.json   ← сгенерированные тайминги субтитров
```

## Установка

```bash
npm install
# офлайн-TTS (если ещё не стоит в окружении):
sudo apt-get install -y espeak-ng ffmpeg
```

## Производство урока

```bash
npm run voiceover                 # сгенерировать озвучку + субтитры для всех уроков
npm run voiceover Lesson01        # только один урок
npm run dev                       # Remotion Studio (превью всех уроков)
npm run render                    # отрендерить Lesson01 → out/Lesson01.mp4
npx remotion render <id> out/<id>.mp4
```

## Как добавить новый урок

1. Добавьте объект в массив `lessons` в `src/lessons.json`: `id`, заголовки,
   окна нарезки клипа (`startSec`/`endSec`), массив `narration` (по строке на
   фразу = одна реплика субтитра), ключевую мысль, пункты аутро.
2. (Опц.) положите свой клип ведущего в `public/` и укажите его в `src`.
3. `npm run voiceover <id>` — сгенерировать озвучку и тайминги.
4. `npx remotion render <id> out/<id>.mp4` — отрендерить.

Длительность сегмента ведущего автоматически подстраивается под длину
озвучки; клип ведущего зацикливается, чтобы покрыть всю реплику.

## Качество озвучки и липсинк — важно

- `espeak-ng` работает офлайн и полностью воспроизводимо, но звучит
  **роботизированно**. Это рабочий по умолчанию движок для этого окружения,
  где облачные TTS (OpenAI, ElevenLabs) и HuggingFace закрыты по сети.
- **Замена на качественный TTS** — одна функция: в
  `scripts/generate-voiceover.mjs` поменяйте `synthLine()` на вызов нужного
  провайдера (или офлайн-Piper при доступе к моделям). Остальной пайплайн
  (тайминги, склейка, субтитры) не меняется.
- Губы ведущего **не синхронизированы** с TTS (это отдельный клип). Для
  настоящего липсинка нужен AI-аватар-сервис (HeyGen/D-ID) либо использовать
  родную озвучку клипа.

## Браузер для рендера

`remotion.config.ts` сам находит установленный Chromium (в т.ч. Playwright
`/opt/pw-browsers/chromium-*`) и использует режим `chrome-for-testing`, чтобы
не качать заблокированный headless-shell. Переопределить путь:
`REMOTION_BROWSER_EXECUTABLE=/путь/к/chrome npm run render`.
