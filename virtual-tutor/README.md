# Virtual Tutor — курсовой «виртуальный человек» на Remotion

Отдельный Remotion-проект, который собирает обучающие уроки вокруг
**реалистичного AI-видео ведущего**.

## Идея и роль Remotion

Сам реалистичный человек (ходит/сидит/говорит/эмоции) генерируется во
внешнем **AI-видеосервисе** (как клип `public/presenter.mp4`), потому что
фотореалистичную фигуру нельзя нарисовать кодом. **Remotion отвечает за
сборку урока**: интро, говорящий сегмент с подписями и плашкой, b-roll с
ключевой мыслью, аутро, единый брендинг — и за повторяемость: новый урок =
новый клип + правка данных, а структура и стиль остаются.

```
public/presenter.mp4   ← реалистичный AI-клип персонажа (ваш ассет)
src/lesson-data.ts     ← ЕДИНСТВЕННЫЙ файл, который правите под новый урок
src/theme.ts           ← цвета/шрифты/название курса (ребрендинг)
src/Lesson.tsx         ← таймлайн: Intro → Presenter → B-roll → Outro
src/components/         ← сцены и оверлеи (плашка, субтитры, брендинг)
```

## Команды

```bash
npm install
npm run dev                       # Remotion Studio (превью в браузере)
npm run render                    # → out/lesson.mp4
npm run lint                      # проверка типов
```

## Как сделать новый урок

1. Сгенерируйте/снимите клип ведущего и положите в `public/` (можно заменить
   `presenter.mp4` или добавить новый файл и указать его в `lesson-data.ts`).
2. Откройте `src/lesson-data.ts` и отредактируйте: заголовок, имя ведущего,
   окна нарезки клипа (`startSec`/`endSec`), субтитры, ключевую мысль, аутро.
3. `npm run dev` — посмотреть, `npm run render` — отрендерить.

## Озвучка (TTS)

Внешние TTS-сервисы в этом окружении закрыты по сети, поэтому озвучка
подключается **файлом**: сгенерируйте `voiceover.mp3` (офлайн или в
доступном провайдере), положите в `public/` и раскомментируйте `<Audio>` в
`src/Lesson.tsx`. Субтитры в `lesson-data.ts` синхронизируйте по таймкодам.

## Браузер для рендера

`remotion.config.ts` автоматически находит установленный Chromium
(в т.ч. Playwright `/opt/pw-browsers/chromium-*`) и использует режим
`chrome-for-testing`, чтобы не качать заблокированный headless-shell.
Переопределить путь: `REMOTION_BROWSER_EXECUTABLE=/путь/к/chrome npm run render`.

## Дальнейшее развитие

- **Несколько уроков**: вынести `lesson-data` в массив и зарегистрировать
  несколько `<Composition>` или использовать параметризованный рендер.
- **3D-аватар (Three.js)**: возможен через `@remotion/three`, но требует
  доступ к моделям (Ready Player Me / Mixamo), которые здесь заблокированы.
  Реализм будет стилизованным — для фотореализма остаётся AI-видео.
