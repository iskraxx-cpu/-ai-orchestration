# imagine

CLI для генерации и редактирования изображений через **Google Gemini 2.5 Flash Image**
(«Nano Banana»). Одна модель закрывает три задачи:

- 🎨 **генерация по описанию** — текст → картинка (дизайн, иллюстрации, концепты);
- ✏️ **редактирование фото** — правки по инструкции с сохранением остального;
- 🛋️ **вписывание предметов** — берёт предмет с одного фото и фотореалистично
  встраивает его в сцену с другого.

Без сторонних зависимостей — только стандартная библиотека Python (3.10+).
Работает сразу после клонирования.

## Установка

```bash
# 1. Получите ключ: https://aistudio.google.com/apikey
cp .env.example .env          # и впишите GEMINI_API_KEY
#   или: export GEMINI_API_KEY="..."
```

Ничего ставить через pip не нужно.

## Использование

```bash
# Генерация по описанию
python -m imagine gen "минималистичный логотип кофейни, бежевый фон, плоский стиль"

# Несколько вариантов и заданное соотношение сторон
python -m imagine gen "постер фантастического города на закате" --n 3 --aspect 16:9

# Редактирование фото
python -m imagine edit photo.jpg "замени фон на зимний лес, сохрани человека"

# Вписать предмет в сцену: фото-1 = комната, фото-2 = диван
python -m imagine compose room.jpg sofa.png \
    --prompt "размести диван со второго фото в комнате с первого, подгони свет и тени"
```

Результаты сохраняются в папку `outputs/` (меняется флагом `--out`).

## Команды

| Команда   | Назначение                                  | Входные фото |
|-----------|---------------------------------------------|--------------|
| `gen`     | сгенерировать по тексту                      | —            |
| `edit`    | отредактировать одно изображение             | 1            |
| `compose` | скомбинировать / вписать предмет             | 2+           |

Общие флаги: `--n` (число вариантов), `--aspect` (1:1, 16:9, 9:16, …),
`--out` (папка), `--model`, `--key`.

## Структура

```
imagine/
  client.py   — клиент Gemini API (urllib, без зависимостей)
  cli.py      — разбор команд и сохранение результатов
  __main__.py — точка входа `python -m imagine`
```
